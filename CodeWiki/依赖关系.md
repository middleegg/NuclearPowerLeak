# 依赖关系

## 1. 依赖管理策略

### 1.1 原则声明

本项目严格遵循 Mindustry Mod 开发的依赖规范：
- **核心依赖（Mindustry / Arc）**：使用 `compileOnly`，**不打入最终 JAR**
- **第三方库**：仅在确实需要且 Mindustry 未内置时，使用 `implementation` 打入 JAR

> 🔍 **为什么？** Mindustry 运行时已自带 Arc 和 Mindustry API 类。若用 `implementation` 会将整个 Mindustry 打进 Mod JAR，造成体积膨胀和类冲突。

参考：[build.gradle#L28-L34](file:///d:/NuclearPowerLeak-master/build.gradle#L28-L34)

依赖声明代码：[build.gradle#L48-L50](file:///d:/NuclearPowerLeak-master/build.gradle#L48-L50)

```groovy
dependencies{
    compileOnly mindustryVersion == "be" 
        ? "Anuken:MindustryBuilds:latest" 
        : "Anuken:Mindustry:$mindustryVersion"
}
```

### 2.2 Mindustry 版本切换

`ext.mindustryVersion` 支持三种取值：

| 值 | 含义 | 下载源 |
|----|------|--------|
| `v<数字>`（如 `v159.5`） | 指定正式 Release | GitHub Release 下载 dependencies.jar |
| `"latest"` | 最新正式 Release | Release 页最新版 |
| `"be"` | 最新 Bleeding-Edge 提交 | `MindustryBuilds` 仓库 |

### 2.3 传递性依赖（来自 Mindustry）

Mindustry 本身依赖的核心框架（自动继承，无需声明）：

| 框架 | 包名前缀 | 在本项目中的用途 |
|------|----------|-----------------|
| **Arc** | `arc.*` | 图形、IO、日志、集合、数学工具、UI Scene2D |
| **GWT** | 无需直接使用 | 跨平台兼容 |

项目中高频使用的 Arc 类：
- `arc.util.Log` - 日志输出
- `arc.graphics.Color` - 颜色定义
- `arc.struct.Seq` - 有序集合（替代 JDK List）
- `arc.math.Mathf` - 数学工具
- `arc.scene.ui.layout.Table` - UI 布局
- `arc.Core` - 全局核心（图集、Bundle 等）

### 4.1 物品贴图映射

每个自定义物品需要对应的 PNG 贴图，路径规则：

| 物品字段 | 贴图文件名 | 路径 |
|----------|-----------|------|
| `bigIron` | `bigIron.png` | `assets/sprites/items/` |
| `Tcoal` | `Tcoal.png` | `assets/sprites/items/` |
| `sulFurFrag` | `sulFurFrag.png` | `assets/sprites/items/` |
| `magent` | `magent.png` | `assets/sprites/items/` |
| `nuclearFluid` | `nuclearFluid.png` | `assets/sprites/liquid/` |
| `dirtySolution` | `dirtySolution.png` | `assets/sprites/liquid/` |
| ... | ... | ... |

完整清单：[资源与国际化](./资源与国际化.md)

### 4.2 加载时资源查找机制

Mindustry 在加载 Mod 时自动：
1. 将 `assets/sprites/` 下 PNG 打包进图集
2. 自动拼接命名：`{modId}-{contentName}`，如 `nu-bigIron`
3. 通过 `Core.atlas.find("nu-frog")` 可直接查找 Frog 图标

示例：[nu.java#L24](file:///d:/NuclearPowerLeak-master/src/Npl/nu.java#L24)

## 5. Gradle 仓库配置

项目在 `repositories` 中配置了 3 个仓库来源（优先级从上到下）：

| 仓库类型 | URL 基础 | 用途 |
|----------|----------|------|
| Maven Central | `mavenCentral()` | 通用 Java 库（当前未使用） |
| Ivy（Release） | `https://github.com/` + `/[org]/[module]/releases/download/[rev]/dependencies.jar` | 下载正式版 Mindustry 依赖 |
| Ivy（Latest Release） | `https://github.com/` + `/[org]/[module]/releases/[rev]/download/dependencies.jar` | `latest` 版本模式 |
| Ivy（BE 构建） | `https://github.com/` + `/[org]/[module]/releases/download/master/[rev].jar` | Bleeding-Edge 构建 |
