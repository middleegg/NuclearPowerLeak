# 构建与运行

## 1. 环境准备

### 1.1 必备软件

| 软件 | 版本要求 | 用途 | 备注 |
|------|----------|------|------|
| **JDK** | 17 | Java 编译运行 | **必须**，推荐 Temurin 发行版 |
| **Gradle** | 随项目提供 Wrapper | 构建工具 | 无需单独安装，使用 `gradlew` 即可 |
| **Android SDK** | 可选（API 30+） | 构建 Android 兼容版 | 仅在需要跨平台时必需 |
| **Mindustry** | v158 及以上 | 运行 Mod 的宿主游戏 | 官网 / Steam 下载 |

### 1.2 环境变量（仅 Android 构建需要）

如需构建 Android 兼容版，需设置以下任一环境变量：
- `ANDROID_HOME`
- 或 `ANDROID_SDK_ROOT`

变量值为 Android SDK 根目录路径，且需确保：
- 已安装 API Level 30+ 平台
- 已安装 Build Tools（推荐 30.0.1+）
- Build Tools 目录已加入 `PATH`（用于 `d8` 命令）

### 1.3 验证环境

```bash
# 验证 Java 版本
java -version
# 期望输出：openjdk version "17.0.x" ...

# Windows 下验证 Gradle Wrapper 可用
gradlew.bat --version
```

## 2. 构建方式对比

本项目提供 3 种构建方式，适用不同场景：

| 构建方式 | 命令 | 输出文件 | 适用平台 | 说明 |
|----------|------|----------|----------|------|
| **桌面快速构建** | `gradlew jar` | `build/libs/NuclearPowerLeak-masterDesktop.jar` | 仅 PC (Windows/Mac/Linux) | 开发调试用，最快 |
| **跨平台本地构建** | `gradlew deploy` | `build/libs/NuclearPowerLeak-master.jar` | PC + Android | 需 Android SDK |
| **CI/CD 自动构建** | Push/PR 触发 GitHub Actions | Artifacts 下载 | PC + Android | 推荐发布用 |

## 3. 桌面快速构建（推荐用于开发调试）

### 3.1 操作步骤

```bash
# 1. 进入项目根目录
cd NuclearPowerLeak-master

# 2. 执行构建
# Windows
gradlew.bat jar

# Linux / Mac
./gradlew jar
```

### 3.2 构建产物说明

执行成功后，`build/libs/` 目录下生成：
- **NuclearPowerLeak-masterDesktop.jar**：桌面版 JAR 包

> ⚠️ **注意**：此版本仅可用于桌面版 Mindustry，**不能**用于 Android 版。

### 3.3 Gradle jar Task 解析

[build.gradle#L74-L88](file:///d:/NuclearPowerLeak-master/build.gradle#L74-L88)

该 Task 执行以下操作：
1. 编译 Java 源码至 `build/classes/java/main/`
2. 打包运行时依赖（如有）
3. 包含根目录 `mod.hjson` 元数据文件
4. 包含 `assets/` 目录下所有资源（sprites、bundles）
5. 输出文件名格式：`${project.name}Desktop.jar`

## 4. 跨平台本地构建（PC + Android）

### 4.1 前置条件

确认已完成：
- 设置 `ANDROID_HOME` 环境变量
- 安装了 Android API 平台（含 `android.jar`）
- `d8` 命令在 PATH 中（Android Build Tools 自带）

### 4.2 操作步骤

```bash
# Windows
gradlew.bat deploy

# Linux / Mac
./gradlew deploy
```

### 4.3 deploy Task 内部流程

[build.gradle#L90-L103](file:///d:/NuclearPowerLeak-master/build.gradle#L90-L103)

```
deploy (Jar Task)
    ├── dependsOn jar          # 产出 Desktop JAR
    ├── dependsOn jarAndroid   # 产出 Android DEX 版 JAR
    │       └── 内部调用 d8 命令：
    │           ├── 收集依赖 classpath（含 android.jar）
    │           ├── 对 Desktop JAR 做 desugar + dex
    │           │   （--min-api 14）
    │           └── 输出 ${projectName}Android.jar
    │
    ├── 合并两个 JAR 内容
    ├── 输出 ${projectName}.jar
    └── doLast 删除中间 Android.jar
```

### 4.4 产物

最终产物：`build/libs/NuclearPowerLeak-master.jar`
- 内部同时包含 `.class`（桌面）和 `classes.dex`（Android）
- 可同时在 PC 版和 Android 版 Mindustry 中加载

## 5. CI/CD 自动构建（推荐发布）

### 5.1 触发方式

项目已配置 GitHub Actions：`.github/workflows/commitTest.yml`

**触发条件**：
- 向仓库 `push` 代码
- 或向仓库提交 `pull_request`

### 5.2 工作流步骤

| 步骤 | 说明 |
|------|------|
| Checkout | 拉取代码 |
| Setup PATH | 将 Android Build Tools 34.0.0 加入 PATH |
| Setup JDK 17 | 安装 Temurin JDK 17 |
| Build mod jar | 执行 `chmod +x ./gradlew && ./gradlew deploy` |
| Upload artifact | 上传 `build/libs/*.jar` 作为构建产物 |

### 5.3 获取构建产物

1. 打开 GitHub 仓库 **Actions** 标签页
2. 选择最近一次成功的构建记录
3. 在 **Artifacts** 区域找到 `NuclearPowerLeak-master` 下载链接
4. 下载 ZIP 并解压，即可获得跨平台 JAR 包

> 💡 GitHub UI 限制：产物以 ZIP 形式下载，内部才是真正的 JAR 文件。

## 6. Mod 安装与运行

### 6.1 获取 Mindustry

从以下途径之一获取游戏：
- 官网：https://mindustrygame.github.io/
- Steam：搜索 "Mindustry" 购买下载
- GitHub Releases：https://github.com/Anuken/Mindustry/releases

### 6.2 Mod 安装步骤

#### PC 版
1. 启动 Mindustry
2. 主菜单 → **"模组 (Mods)"** 按钮
3. 点击 **"导入 Mod (Import Mod)"**
4. 选择构建好的 JAR 文件（`NuclearPowerLeak-masterDesktop.jar` 或跨平台版）
5. 确认导入后，在 Mod 列表中启用 NuclearPowerLeak
6. 重启游戏生效

#### Android 版
1. 将跨平台 JAR 拷贝到手机存储
2. 启动 Mindustry Android 版
3. 模组 → 导入 → 从文件管理器选择 JAR
4. 启用后重启

### 6.3 验证 Mod 加载成功

1. 启动游戏后会看到 "frog" 弹窗（延迟显示），内含青蛙图片和 "behold" 文字
2. 查看星图，应能看到新的黄色星球 **Azer**
3. 在科技树或沙盒模式中检查是否有新增物品（生铁、T型煤等）

### 6.4 体验 Azer 星球

1. 从主菜单进入 **"战役"** 或 **"自定义游戏"**
2. 选择星球 **Azer**
3. 开局获得 100 生铁
4. 在方块菜单中找到 `test-block`（测试方块）和 `redenmore` 放置体验

## 7. 常见问题排查

### Q1: 执行 `gradlew jar` 失败，提示 Mindustry 依赖下载失败

**原因**：国内网络访问 GitHub 受限，无法从 Mindustry Releases 下载 `dependencies.jar`
**解决**：项目已在 [build.gradle](file:///d:/mc/Mindustry/My%20mod/NuclearPowerLeak/build.gradle) 中内置 GitHub 镜像（`gh-proxy.com`、`ghproxy.net`）作为 ivy 仓库，并保留 GitHub 直连兜底。Gradle 会按顺序尝试，第一个可用即返回。

若镜像下载仍超时（大文件 15MB 通过镜像较慢），可手动下载到本地 `libs/` 目录：
1. 用浏览器或下载工具从镜像下载对应版本的 `dependencies.jar`，例如 v159.5：
   `https://ghproxy.net/github.com/Anuken/Mindustry/releases/download/v159.5/dependencies.jar`
2. 将文件重命名为 `Mindustry-v159.5.jar`（版本号需与 `build.gradle` 中 `mindustryVersion` 一致），放入项目根目录的 `libs/` 文件夹
3. `build.gradle` 的 `dependencies` 块会自动检测到本地 jar 并优先使用，无需再走网络下载
4. 在 IDEA 中重新 Sync Gradle 即可识别 `mindustry.*`、`arc.*` 等依赖

> `libs/` 目录已加入 `.gitignore`，本地 jar 不会提交到仓库。`gradle.properties` 中也增加了下载超时时间（连接 120s，读取 600s）。

### Q2: Mod 导入后游戏崩溃，提示类版本错误

**原因**：编译用 JDK 版本与游戏运行时 JRE 不匹配  
**解决**：确认编译时使用 JDK 17（不要用更高版本）

### Q3: Android 版加载失败

**原因**：使用了 Desktop 版 JAR（无 DEX）  
**解决**：使用 `gradlew deploy` 或 CI 构建的跨平台 JAR

### Q4: 物品名称显示为 `item.nu-bigIron.name`

**原因**：资源 Bundle 未正确加载  
**解决**：
- 检查构建的 JAR 内是否包含 `assets/bundles/` 目录
- 确认 `mod.hjson` 的 `name` 字段为 `nu`（与资源前缀一致）
