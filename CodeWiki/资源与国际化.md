> **根目录**：`assets/`  
> **子目录**：`assets/sprites/`（图片资源）、`assets/bundles/`（多语言文本）

## 1. 资源打包机制

Mindustry 在加载 Mod JAR 时自动读取 `assets/` 目录，并将内容**合并**到自身资源系统中：

| 资源类型 | 处理方式 |
|----------|---------|
| `assets/sprites/*.png` 及其子目录 | 打包进 Texture Atlas（图集），自动命名前缀 `nu-` |
| `assets/bundles/bundle_{locale}.properties` | 注册为国际化 Bundle，附加在原版 Bundle 后（可覆盖） |

### 1.1 Gradle 打包配置

`build.gradle` 的 `jar` Task 显式包含了这些资源：
```groovy
jar{
    from("assets/"){
        include "**"       // 包含 assets 下所有文件和子目录
    }
    from(projectDir){
        include "mod.hjson"  // 包含 Mod 元数据文件
    }
}
```
位置：[build.gradle#L81-L88](file:///d:/NuclearPowerLeak-master/build.gradle#L81-L88)

## 3. 国际化 Bundle 详解

Mindustry 基于 Java Properties 格式的 i18n 机制。Mod 的 Bundle 文件自动附加在原版 Bundle 之后，可补充或覆盖键值。

### 3.1 文件列表

| 文件 | 语言代码 | 适用地区 |
|------|---------|---------|
| `bundle.properties` | 默认（英文） | 未匹配到具体语言时使用 |
| `bundle_zh_CN.properties` | zh_CN | 简体中文（中国地区） |

### 3.2 键名规则

Mindustry 采用统一的 `{类型}.{资源键}.{属性}` 命名模式：

| 键名模式 | 示例 | 说明 |
|---------|------|------|
| `item.{modId}-{itemName}.name` | `item.nu-bigIron.name` | 物品显示名 |
| `item.{modId}-{itemName}.description` | `item.nu-bigIron.description` | 物品短描述 |
| `item.{modId}-{itemName}.details` | `item.nu-bigIron.details` | 物品详细背景故事 |
| `block.{modId}-{blockName}.name` | `block.nu-test-block.name` | 方块显示名 |
| `block.{modId}-{blockName}.description` | `block.nu-test-block.description` | 方块描述 |
| `liquid.{modId}-{liquidName}.name` | `liquid.nu-nuclearFluid.name` | 液体显示名 |
| `liquid.{modId}-{liquidName}.description` | `liquid.nu-nuclearFluid.description` | 液体描述 |
| `unit.{modId}-{unitName}.name` | `unit.nu-arcnelidia.name` | 单位显示名 |
| `unit.{modId}-{unitName}.description` | `unit.nu-arcnelidia.description` | 单位描述 |
| `unit.{modId}-{unitName}.details` | `unit.nu-arcnelidia.details` | 单位详细背景 |
| `planet.{modId}-{planetName}.name` | `planet.nu-Azer.name` | 星球显示名 |
| `stat.{statName}` | `stat.reversible` | 自定义统计属性显示名 |

## 4. 资源加载调试

### 4.1 验证 Sprite 是否正确加载

```java
// 调试代码片段
Core.atlas.addRegion("nu-bigIron", ...);  // （Mindustry 自动处理）
TextureRegion region = Core.atlas.find("nu-bigIron");
if (region == Core.atlas.find("error")) {
    Log.err("Sprite nu-bigIron not found!");
}
```

### 4.2 验证 Bundle 键值

```java
String name = Core.bundle.get("item.nu-bigIron.name");
// 期望返回："生铁"（中文环境）或 "bigIron"（英文环境）
```

### 4.3 常见问题与修复

| 问题现象 | 可能原因 | 修复方法 |
|---------|---------|---------|
| 物品名显示为 `item.nu-bigIron.name` | Bundle 未加载或键名错 | 检查 JAR 内是否包含 bundle 文件、键名拼写 |
| 物品图标为红黑棋盘（占位） | Sprite 未找到 | 检查 PNG 文件名与 Java 物品 name 是否一致 |
| 中文物品名乱码 | properties 文件编码错误 | 使用 native2ascii 或 IDE 设置「ISO-8859-1 with Unicode escape」保存 |
| 瓶装磁暴 description 不显示 | 错键名 descrpition → description | 修改为正确 `description` |
