# 项目总览

## 1. 项目简介

**NuclearPowerLeak（核泄漏）** 是一款基于 [Mindustry](https://github.com/Anuken/Mindustry)（像素工厂）游戏的 Java Mod（模组）。项目围绕"核灾厄"主题，为游戏引入全新的物品体系、液体体系、自定义星球、多配方可配置方块等游戏内容。

### 1.1 核心主题
本模组以"核泄漏灾难后的世界"为叙事背景，引入了**三灾厄**概念：
- **第一灾厄 - 铀（Uranium）**：一切灾厄的开端
- **第二灾厄 - 铊化物（Thallide）**：人为封锁的剧毒结晶体
- **第三灾厄 - 瓶装磁暴（Bottled Magentic Storm）**：象征人类联邦葬礼的礼炮

## 2. 核心功能一览

### 2.1 自定义物品系统（16种新物品）
| 类别 | 代表物品 | 特色属性 |
|------|----------|----------|
| 基础矿物 | 生铁 (bigIron)、T型煤 (Tcoal)、硫芯 (sulFurFrag) | 硬度、成本、可燃性 |
| 工业材料 | 单晶体、磁铁、脆纶、气浮石、碱银 | 可逆性、磁性、稳定性、电荷 |
| 有机资源 | 原胶、胶种、橡胶 | 可燃性、硬度 |
| 核灾厄资源 | 铀晶、原铀、铊化物、铀、瓶装磁暴 | 放射性、爆炸性、高电荷、高磁性 |

### 2.2 自定义液体系统（4种新液体）
| 液体 | 特性 |
|------|------|
| 核流体 (nuclearFluid) | 高温，绿色荧光 |
| 脏溶液 (dirtySolution) | 高温高粘度，可燃可反应，不可蒸发 |
| 液氧 (liquidOxygen) | 极低温，冷却剂，低粘度 |
| 奇液 (strangeLiquid) | 低温，特殊物理属性 |

### 2.3 自定义星球 - Azer（阿泽尔）
- 围绕太阳旋转的独立星球
- 自定义大气颜色、云层效果
- 初始物资：100 生铁
- 启用波次系统，绿色敌方阵营
- 5 分钟准备时间，76 秒波次间隔
- 支持 RTS AI

### 2.4 可配置多配方方块
- **ConfigurableBlock**：一种方块支持多个生产配方，玩家可在游戏中切换模式
- 支持按索引切换、按输出物品切换两种配置方式
- 内置进度条显示、配方选择 UI
- 示例方块 `test-block` 包含 3 种配方模式

### 2.5 扩展物品属性系统
在原版 Mindustry 物品属性基础上扩展了三种新属性：
- **可逆性 (Reversible)**：百分比显示，影响某些可逆反应效率
- **磁性 (Magentic)**：百分比显示，影响磁力交互
- **稳定性 (Stability)**：百分比显示，影响物品/反应稳定程度

### 2.6 通用配方数据结构
`Recipe` 类提供链式 API 定义配方，支持：
- 物品/液体/Payload 多类型输入输出
- 可配置制作时间
- 可配置优先级

## 3. 技术亮点

| 亮点 | 说明 |
|------|------|
| **纯 Java 实现** | 完全基于 Mindustry Java Mod API，兼容 PC 和 Android 双平台 |
| **链式配置 API** | 方块、物品、配方均采用链式初始化风格，代码可读性高 |
| **多配方切换机制** | ConfigurableBlock 实现运行时配方切换，无需重建方块 |
| **自定义属性扩展** | 通过继承 Item 类 + 自定义 Stat 实现新属性无缝接入原版 UI |
| **完整 CI/CD** | GitHub Actions 自动构建，每次提交自动产出跨平台 JAR |
| **双语言国际化** | 内置中英文 Bundle，支持物品描述本地化 |

## 4. 应用场景

1. **学习 Mindustry Mod 开发**：本项目结构清晰，适合作为 Java Mod 入门范例
2. **扩展游戏体验**：新增核工业产业链，丰富中后期游戏内容
3. **自定义星球玩法**：Azer 星球提供独立的游玩环境和资源体系
4. **二次开发基础**：Recipe、ConfigurableBlock 等通用类可直接复用
